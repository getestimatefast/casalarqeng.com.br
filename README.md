# Casal Arq & Eng

Site institucional da Casal Arq & Eng para o domínio **casalarqeng.com.br**.

## Objetivo

Landing page profissional para apresentar serviços de arquitetura, engenharia, gestão de obras, construção industrializada, Steel Frame, kits estruturais, interiores e acompanhamento técnico.

## Estrutura inicial

- `index.html`: página principal do site
- `styles.css`: estilos visuais
- `script.js`: interações simples

## Publicação

Este projeto pode ser publicado em GitHub Pages, Vercel, Netlify, Hostinger ou outro provedor de hospedagem estática.
